# Polygon Control

Веб-приложение для управления компьютерными клубами: PIN-вход для владельца,
сотрудников и инвесторов, смены и кассы, расходы, зарплата, оборудование,
заявки и журнал действий.

## Локальный запуск (для проверки)

```bash
npm install
npm start
```

Откроется на `http://localhost:3000`. Данные хранятся в файле `server/data.sqlite`.

Для разработки с горячей перезагрузкой фронтенда:

```bash
npm install --prefix client
npm run dev --prefix client   # откроет http://localhost:5173, проксирует /api на :3000
node server/index.js          # в отдельном терминале
```

## Деплой на Railway

1. Залейте этот проект в свой репозиторий на GitHub.
2. На railway.com → **New Project → Deploy from GitHub repo** → выберите репозиторий.
3. Railway сам определит Node.js и выполнит `npm install` (что заодно соберёт
   фронтенд через `postinstall`) и `npm start`.
4. **Обязательно добавьте Volume** (Railway → ваш сервис → Settings → Volumes),
   смонтированный, например, в `/data`, и добавьте переменную окружения:
   ```
   DB_PATH=/data/data.sqlite
   ```
   Без этого база данных будет удаляться при каждом новом деплое.
5. (Необязательно, но рекомендуется) добавьте переменную `API_KEY` с любым
   секретным значением — тогда запись данных будет закрыта простым ключом
   API. Если её не задать, приложение всё равно будет работать, но без этой
   защиты.

## Подключение домена polygon-control.kz

1. В Railway откройте ваш сервис → **Settings → Networking → Custom Domain**,
   введите `polygon-control.kz` (и/или `www.polygon-control.kz`).
2. Railway покажет CNAME-запись вида `xxxx.up.railway.app`.
3. В панели регистратора домена (hoster.kz) добавьте CNAME-запись:
   - Имя: `@` (или `www`)
   - Значение: то, что показал Railway
4. Подождите обновления DNS (обычно 10–60 минут).

## Структура проекта

- `server/` — backend на Express + SQLite. Простое key-value хранилище
  (`/api/kv/:key`), которое использует фронтенд — так все данные (клубы,
  сотрудники, смены и т.д.) реально сохраняются на сервере, а не в браузере.
- `client/` — React-приложение (Vite). Собирается в `client/dist` и
  отдаётся сервером как статика.
